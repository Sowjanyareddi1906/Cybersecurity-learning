
# Reconnaissance Notes

Reconnaissance is the process of collecting information about a target before security testing.

## Types

### Passive Reconnaissance

Information is collected without directly interacting with the target infrastructure.

Examples:

- Search engines
- Public documents
- Public DNS information
- OSINT

### Active Reconnaissance

Direct interaction with the authorized target.

Examples:

- Port scanning
- Service enumeration
- Web enumeration

## Common Information

- IP addresses
- Domains
- Subdomains
- Open ports
- Services
- Technologies
- Web endpoints

## Common Tools

- Nmap
- DNS tools
- Burp Suite
- Browser Developer Tools

## Important

Reconnaissance must only be performed against systems where you have authorization.
