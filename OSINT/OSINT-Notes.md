
# OSINT Notes

OSINT stands for Open-Source Intelligence.

It involves collecting and analyzing information from publicly available sources.

## Common OSINT Sources

- Search engines
- Public websites
- Social media
- Public documents
- Domain information
- DNS information
- Metadata

## OSINT Workflow

1. Define the objective
2. Collect publicly available information
3. Verify information using multiple sources
4. Organize findings
5. Document the evidence

## Important Concepts

- Domain enumeration
- DNS information
- Metadata analysis
- Username investigation
- Public document analysis
- Search operators

## Ethics

OSINT should be performed using publicly available information and within legal and ethical boundaries.
