# CTF Learning

I use Capture The Flag challenges to improve practical cybersecurity skills.

## Categories

- Web Security
- OSINT
- Cryptography
- Linux
- Network Security
- Forensics
- Reverse Engineering

## Approach

1. Understand the challenge.
2. Identify the category.
3. Enumerate available information.
4. Test possible approaches.
5. Document the technique.
6. Record what I learned.

All activities are performed in authorized labs and CTF environments.
