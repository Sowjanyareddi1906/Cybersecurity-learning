# CTF Learning

I use Capture The Flag challenges to improve practical cybersecurity skills.

## Categories

- Web Security
- OSINT
- Cryptography
- Linux
- Network Security
- Forensics
- Reverse Engineering

## Approach

1. Understand the challenge.
2. Identify the category.
3. Enumerate available information.
4. Test possible approaches.
5. Document the technique.
6. Record what I learned.

All activities are performed in authorized labs and CTF environments.

# CTF Methodology

## 1. Reconnaissance

First understand what is provided.

Look for:

- IP addresses
- URLs
- Files
- Ports
- Services
- Source code
- Metadata

## 2. Enumeration

Gather more information about the target.

For example:

- Open ports
- Running services
- Web directories
- Technologies
- User-accessible functionality

## 3. Analyze

Understand how the application, file, or service works.

## 4. Test

Try techniques relevant to the challenge category.

## 5. Find the Flag

Look for hidden or exposed information according to the challenge objective.

## 6. Document

Record:

- Challenge name
- Category
- Recon steps
- Tools used
- Important observations
- Solution concept
- What I learned

## Rule

Practice only in authorized CTFs, labs, and systems where testing is permitted.
